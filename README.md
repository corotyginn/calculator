# 🧮 Advanced Python CLI Calculator

A robust and interactive command-line calculator written in Python. This project was built to demonstrate clean code principles, type hinting, and comprehensive error handling.

## ✨ Features

*   **Basic Arithmetic:** Addition, subtraction, multiplication, and division.
*   **Advanced Operations:** Exponentiation (power), square root, and modulo.
*   **Bulletproof Error Handling:**
    *   Prevents division by zero.
    *   Validates user input (doesn't crash if you type a letter instead of a number).
    *   Handles negative numbers for square root calculations.
*   **Clean Architecture:** Uses a dictionary mapping for operations instead of long `if/elif` chains, making the code scalable and easy to read.
*   **Type Hinting:** Fully annotated with Python type hints for better readability and IDE support.

## 🛠️ Tech Stack

*   **Language:** Python 3.x
*   **Libraries:** Built-in `math` and `sys` modules (No external dependencies required).
